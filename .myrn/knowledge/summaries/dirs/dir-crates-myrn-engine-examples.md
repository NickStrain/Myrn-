# crates/myrn-engine/examples/

Holds example binaries for the myrn-engine crate, used for manual exploration rather than as library code. Currently contains simcheck.rs, a temporary debug tool that opens the engine in the current directory, embeds each command-line argument, and prints the top dot-product matches from the vectors table.
